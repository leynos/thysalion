# Migration from 0.1.0 to 0.2.0

This note describes the Rust API migration from 0.1.0 to the planned 0.2.0
release. The crate remains at 0.1.0; this migration note does not indicate that
0.2.0 has been released.

## New validated palette API

The planned 0.2.0 release introduces `scene::palette::Passability` and
`scene::palette::FacePassability` for validated palette and pathfinding values;
there was no palette-domain `Passability` type in 0.1.0. Each face field uses
`FacePassability` rather than `bool`. Convert a face boolean with
`FacePassability::from(true)` or `FacePassability::new(false)`, or use
`Passability::open` and `Passability::closed` for uniform values. Read a face
with `is_passable`.

## Scene document API

In 0.1.0, `scene::document::Passability` was the public scene-document type
with six `bool` fields. In 0.2.0 it is renamed
`scene::document::PassabilityDocument`; callers should rename their type
references and wrap or convert each field boolean as
`PassabilityFaceDocument::new(bool)` or `PassabilityFaceDocument::from(bool)`
(`.into()` also works). Read a face with `is_passable`.
`Palette::from_document` converts the wire value to the validated palette
representation.

These are Rust source API changes. JSON and MessagePack continue to encode six
flat boolean fields, and the scene format version remains 1.0. Existing scene
files do not need a data migration.
