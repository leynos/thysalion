# Migration from 0.1.0 to 0.2.0

This note describes the Rust API migration from 0.1.0 to the planned 0.2.0
release. The crate remains at 0.1.0; this migration note does not indicate that
0.2.0 has been released.

## Validated palette API

In validated-domain `Passability`, `pos_x`, `neg_x`, `pos_y`, `neg_y`, `pos_z`,
and `neg_z` change from `bool` to `FacePassability`. Use
`scene::palette::Passability` and `scene::palette::FacePassability` for
validated palette and pathfinding values. Convert each face boolean with
`FacePassability::from(true)` or `FacePassability::from(false)`, or use
`Passability::open` and `Passability::closed` for uniform values. Read a face
with `is_passable`.

## Scene document API

Callers building scene documents use `scene::document::PassabilityDocument`.
Its six named fields use `PassabilityFaceDocument`; construct a face with
`PassabilityFaceDocument::new(bool)` or convert a boolean with `.into()`, and
read it with `is_passable`. `Palette::from_document` converts the wire value to
the validated palette representation.

These are Rust source API changes. JSON and MessagePack continue to encode six
flat boolean fields, and the scene format version remains 1.0. Existing scene
files do not need a data migration.
